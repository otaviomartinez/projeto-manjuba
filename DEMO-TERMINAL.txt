BATALHA DE TERMINAL - DEMONSTRACAO INTERMEDIARIA

Base: main do projeto-manjuba, commit fa44c355ab9f582f7d408e94ef5961c98e5b94e2.
Versao demonstrativa para revisao da equipe.

COMO JOGAR
Abra a pasta do repositorio no VS Code.
No terminal MSYS2 UCRT64, dentro desta pasta:

gcc -std=c11 -Wall -Wextra src/main.c src/personagem.c src/turno.c src/batalha.c src/carta.c src/baralho.c -o jogo.exe
./jogo.exe

Alternativa no MSYS2 com make instalado: make e depois ./jogo.exe.
Escolha 1, 2 ou 3 para usar a carta apresentada. Digite 0 para sair.
Para simular os dois combates automaticamente: ./jogo.exe --auto

REGRAS DESTA DEMONSTRACAO
- Tres aliados contra tres inimigos; depois contra um chefe.
- Maior iniciativa age primeiro. Empates mantem a ordem de entrada.
- Derrotados sao ignorados pelo laco da batalha.
- Ataque individual atinge o primeiro inimigo vivo.
- Cura individual atua no proprio personagem, sem ressuscitar.
- Terremoto atinge todos os inimigos vivos.
- Cada aliado tem um baralho independente com tres cartas.
- usarCarta devolve o ID, rotaciona a carta e a main aplica seu efeito.
- Os inimigos usam ataque automatico de seis pontos.
- Vida e baralhos dos aliados persistem entre os dois combates.
- Todos os numeros sao exemplos para testar a integracao, nao balanceamento final.

Os demais modulos foram reutilizados sem alteracao.

OBSERVACOES PARA A EQUIPE
O Makefile foi atualizado para incluir baralho.c e criar build automaticamente.
Esta demonstracao usa o comando direto acima, incluindo baralho.c.
Os baralhos continuam usando inteiros: nesta main, esses inteiros sao IDs de um catalogo Carta[].
Nao retorne Batalha por valor depois de montar ponteiros para seus personagens internos:
eles precisam continuar apontando para a mesma estrutura durante o combate.
Evite sobrescrever a main da equipe sem combinar a integracao.

VALIDACAO
Compilacao com -std=c11 -Wall -Wextra -Werror, sem avisos.
Simulacao automatica concluiu os dois combates com vitoria.
Entrada interativa testada: opcao invalida, cura, ataque em area e sair.
Teste original de batalha executado: alvos, vitoria e derrota com resultados esperados.
Testes nao garantem o balanceamento do jogo.
